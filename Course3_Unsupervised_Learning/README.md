# Course 3 — Unsupervised Learning, Recommenders, Reinforcement Learning

Part of the [Machine Learning Specialization](../) by Andrew Ng (DeepLearning.AI) on Coursera.

## 📚 Course overview

This course covers three major areas of modern machine learning beyond supervised learning: finding structure in unlabeled data, building recommendation systems, and training agents to make decisions through reinforcement learning.

| Week | Topic | Key algorithms |
|---|---|---|

| [Week 2](./Week2/) | Recommender Systems | Collaborative Filtering, Neural Network RecSys |
| [Week 3](./Week3/) | Reinforcement Learning | Deep Q-Learning (DQN) |
