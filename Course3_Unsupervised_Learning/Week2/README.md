## 🎯 Key concepts

- **Collaborative filtering** — predicting user preferences based on the ratings of similar users, without needing item features
- **Cost function for collaborative filtering** — minimizing the difference between predicted and actual ratings across all users and items
- **Content-based filtering** — recommending items based on features of the item and the user profile
- **Neural network recommender** — learning user and item embeddings through a deep learning model to generate personalized recommendations
- **Embeddings** — dense vector representations that capture the latent features of users and items

## 💡 What I learned

- The difference between collaborative filtering (user-based) and content-based filtering (feature-based)
- How to implement a recommender system from scratch using NumPy and TensorFlow
- How neural networks can learn complex user-item relationships through embeddings
- Real-world applications: Netflix, Spotify, Amazon recommendation engines all use these techniques
