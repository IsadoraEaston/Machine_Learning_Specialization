## 🎯 Key concepts

- **K-means clustering** — grouping unlabeled data into clusters based on similarity, using centroid initialization and iterative reassignment
- **Image compression with K-means** — reducing the number of colors in an image by clustering pixel values
- **Anomaly detection** — modeling normal data with a Gaussian distribution and flagging points with low probability density as anomalies
- **Choosing the threshold (epsilon)** — balancing false positives and false negatives when detecting anomalies

## 💡 What I learned

- How unsupervised algorithms find structure in data without labeled examples
- The difference between supervised classification and unsupervised clustering
- How probability density functions can be used to detect outliers in real-world data (e.g., server monitoring, fraud detection)
